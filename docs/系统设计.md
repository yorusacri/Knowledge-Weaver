## 2 数据流

### 2.1 教材上传与解析流程

```
用户上传 PDF/MD/TXT/DOCX 文件
         │
         ▼
  FastAPI /api/textbooks/upload
         │ 保存文件到 data/uploads/
         │ 触发后台解析进程（multiprocessing）
         ▼
  解析进程（独立 Python 进程）
         │ PyMuPDF 逐页解析 PDF
         │ 正则识别章节（"第X章"）
         │ LLM 辅助章节边界检测（fallback）
         ▼
  输出 ParsedTextbook JSON → data/parsed/{book_id}.json
         │
         ▼
  前端轮询 /api/textbooks/{id}/status 显示进度
```

### 2.2 知识图谱构建流程

```
ParsedTextbook JSON
         │
         ▼（逐章节调用 LLM）
  LLM 提取知识点（节点 + 边）
         │
         ▼
  节点：{id, name, definition, category, chapter, page, textbook}
  边：{source, target, relation_type, description}
         │
         ▼
  data/graph/{book_id}_graph.json
```

### 2.3 跨教材整合流程

```
加载所有教材的图谱数据
         │
         ▼
  Embedding 计算候选节点对相似度
         │
         ▼  > 0.85 → 自动合并
           0.70~0.85 → LLM 仲裁
           < 0.70 → 保留为不同节点
         ▼
  整合决策列表（merge/keep/remove）
         │
         ▼
  执行决策 → 更新图谱 → 计算压缩比
```

### 2.4 RAG 问答流程

```
用户输入问题
         │
         ▼
  问题 → embedding → FAISS 检索 top-5 chunks
         │
         ▼
  构建 Prompt（问题 + top-5 chunks + 引用约束）
         │
         ▼
  LLM 生成回答（引用原文）
         │
         ▼
  返回：{answer, citations[], source_chunks[]}
```

## 3 技术选型及理由

| 层级 | 选型 | 理由 |
|------|------|------|
| 后端框架 | FastAPI | 异步高性能，与 Python 深度集成，Pydantic 自动校验 |
| 前端框架 | React (Vite) | 生态丰富，组件化开发，Vite HMR 快 |
| 图谱可视化 | D3.js 力导向图 | 最灵活的 JS 可视化库，支持丰富交互 |
| PDF 解析 | PyMuPDF (fitz) | 逐页解析不过载内存，Python 原生支持 |
| DOCX 解析 | python-docx | 事实标准，成熟稳定 |
| 向量嵌入 | sentence-transformers (BGE-small-zh) | 中文支持好，本地运行免费 |
| 向量存储 | FAISS | 亿级向量高速检索，CPU 友好 |
| LLM | DeepSeek API | 性价比高，中文能力强 |
| 文件存储 | 本地文件系统 + JSON | 轻量级，黑客松场景足够 |

## 4 API 接口一览

### 4.1 教材管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/textbooks/upload` | 上传教材文件 |
| GET | `/api/textbooks` | 获取教材列表 |
| GET | `/api/textbooks/{id}/status` | 获取解析状态 |
| GET | `/api/textbooks/{id}/parsed` | 获取解析结果（章节列表） |
| GET | `/api/textbooks/{id}/chapters/{ch_id}` | 获取章节内容 |
| DELETE | `/api/textbooks/{id}` | 删除教材 |
| POST | `/api/textbooks/{id}/parse` | 重新解析 |

### 4.2 知识图谱

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/graph/{id}` | 获取单本教材图谱 |
| GET | `/api/graph/{id}/build-status` | 获取图谱构建状态 |
| GET | `/api/graph/all` | 获取所有教材合并图谱 |
| POST | `/api/graph/{id}/build` | 触发图谱构建 |

### 4.3 跨教材整合

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/integration/run` | 执行整合 |
| GET | `/api/integration/decisions` | 获取整合决策列表 |
| PATCH | `/api/integration/decisions/{id}` | 修改整合决策 |
| GET | `/api/integration/stats` | 获取整合统计 |
| GET | `/api/integration/compression` | 获取压缩比 |

### 4.4 RAG 问答

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/rag/index` | 构建向量索引 |
| POST | `/api/rag/query` | RAG 问答 |
| GET | `/api/rag/status` | 索引状态 |

### 4.5 多轮对话

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/dialogue/message` | 发送消息 |
| GET | `/api/dialogue/history` | 获取对话历史 |
| DELETE | `/api/dialogue/history` | 清空对话历史 |

### 4.6 健康检查

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
